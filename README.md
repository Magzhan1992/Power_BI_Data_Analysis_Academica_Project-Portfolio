Power BI E-Commerce Analytics Dashboard

Задача: Провести комплексный анализ эффективности e-commerce бизнеса. Ключевая цель — отслеживание динамики продаж, уровня прибыли и операционных показателей (доставка, возвраты) для выявления проблемных зон.

Моя Результат Проекта: Спроектировал и разработал интерактивный дашборд (состоящий из 7 страниц). Настроил расчет ключевых метрик, реализовал визуализацию трендов и настроил срез данных (фильтры по годам, регионам, категориям и складам).

Инструменты: Power BI, DAX (язык формул для расчетов), Power Query.

Результат (в цифрах):
Дашборд позволяет моментально считывать текущую ситуацию в бизнесе:

Общий объем продаж (Total Sales): составил 227,19 млн ₸ (однако зафиксировано падение на -2,7% по сравнению с прошлым месяцем, который составлял 211,06 млн).

Общая прибыль (Total Profit): составила 184,19 млн ₸ (также наблюдается снижение на -3,1%).

Количество заказов (Total Orders): 2001 штука (снижение на -4,8%).

Процент успешных доставок (Delivery Rate): 16,00% (единственный показатель с положительной динамикой — рост на +1,0%).

Процент возвратов (Returns Rate): 16,99% (снижение на -0,4%).

Всего клиентов (Total Clients): 201 человек.

Топ-5 категорий по продажам: Электроника лидирует с показателем 65 млн ₸, далее следуют Одежда (61 млн ₸), Игрушки (39 млн ₸), Мебель (37 млн ₸) и Бытовая техника (25 млн ₸).
